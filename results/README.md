# Results

`paper/` contains a deliberately small set of reference outputs: the main
depth-filter sensitivity figure, the depth-60 `lab_b_mean` QTL scan and effect
summary, a categorical-QTL comparison, and segmentation evaluation metrics.

`generated/` is ignored by Git and is the default destination for new runs.
The original working directory contained hundreds of megabytes of repetitive
plots and intermediate tables; those can be regenerated from the scripts and
are intentionally not versioned here.
